# Agent primer

A plain introduction to how AI agents work, meant to be read before the sources on the reading list. Read it at https://skrtis.github.io/agent-primer/.

The pages are written in an Obsidian vault and copied here with `sync.py`:

```bash
python3 sync.py PATH_TO_VAULT/concepts
git add -A && git commit -m "Update primer" && git push
```
